# Outils pratiques : calculs hors ligne et modèles de travail

Des outils pour vérifier un calcul ou structurer des observations avant une décision. Le projet réunit **35 ressources**, chacune accompagnée d'un tableur, d'une trame CSV, d'un exemple fictif et de sa sortie calculée.

**[Télécharger l'ensemble](https://github.com/vocalisia/outils-pratiques/releases/latest/download/outils-pratiques.zip)** · [Parcourir les ressources](#ressources)

[Lire la documentation et les exemples en ligne](https://vocalisia.github.io/outils-pratiques/)

## Choisir un format

- **Excel / Sheets** : téléchargez le fichier `modele.xlsx` de la ressource, ou importez `trame.csv` dans une copie privée. Les feuilles servent de journal de saisie ; elles ne recalculent pas automatiquement les résultats.
- **Calcul vérifiable** : Python 3.10 ou supérieur suffit, sans installation de bibliothèque. Modifiez une copie privée du JSON d'exemple, puis utilisez la commande indiquée dans la notice.
- **Exemple fictif** : `resultat-exemple.json` montre la sortie réellement calculée du scénario fourni. Ce n'est ni un relevé client, ni un résultat de terrain.

Les ressources sont proposées dans le cadre du portefeuille éditorial des sites indiqués, avec affiliation explicite. Elles ne constituent pas un classement indépendant de ces sites. Les calculs n'interrogent aucun service, n'envoient aucun message et n'effectuent aucune opération financière.

## Exécuter et vérifier

```text
python -X utf8 run.py panel_power resources/tesla-ch-puissance/exemple-fictif.json
python -X utf8 -m unittest -q test_calculations
```

Les résultats numériques sont arrondis à six décimales. Les valeurs manquantes, booléennes, non finies, hors plage ou les formes d'entrée incompatibles sont rejetées selon le calcul. Les ratios sans dénominateur sont renvoyés comme `null`, jamais convertis en réussite ou en pourcentage artificiel.

Les journaux résument les états déclarés par leur utilisateur ; ils ne vérifient pas une preuve externe. Un audit HTML ou XML local n'est ni un rendu JavaScript, ni un contrôle HTTP, ni une inspection Google.

## Conservation des données

Le programme fonctionne hors ligne. Ne publiez pas de données personnelles, de dossiers clients, d'enregistrements, de jetons ou de fichiers confidentiels dans le dépôt. Les exemples inclus sont fictifs. Les montants ne sont pas les tarifs des sites associés.

Version : 25 octobre 2026. Les fichiers XLSX ont été relus structurellement ; leur rendu n'a pas été testé dans toutes les versions d'Excel ou de Sheets. Les calculs sont vérifiés dans le programme Python, indépendamment du tableur.
