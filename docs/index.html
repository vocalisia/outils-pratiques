Documentation du projet

Outils pratiques

Des journaux de travail et des calculs hors ligne pour contrôler un scénario, documenter une observation ou préparer une décision. Le projet comprend 35 ressources, 22 moteurs Python et des exemples entièrement fictifs.

Télécharger le projet complet · Consulter le code et les 62 tests

Les fichiers Excel, CSV et Google Sheets servent de journaux à copier en privé. Ils ne recalculent pas automatiquement. Pour reproduire un calcul, Python 3.10 ou supérieur suffit, sans bibliothèque supplémentaire. Aucun service distant n’est appelé et aucune donnée n’est envoyée.

Téléchargez l’archive, décompressez-la et ouvrez un terminal dans le dossier obtenu. Exécutez la commande indiquée dans la ressource choisie. Modifiez une copie privée du JSON d’entrée pour tester votre propre scénario. Conservez les unités de l’exemple ; n’insérez jamais de données personnelles dans un fichier public.

Les ratios sans dénominateur sont renvoyés sous la forme null. Les calculs rejettent les valeurs non finies ou incompatibles avec leur contrat ; les nombres de sortie sont arrondis à six décimales. Les journaux résument uniquement les états que leur utilisateur déclare. Ils ne certifient aucune preuve externe.

Les ressources sont associées aux sites de notre portefeuille éditorial. Cette affiliation est déclarée dans chaque notice ; le catalogue ne constitue pas un classement indépendant. Les résultats d’exemple ne représentent aucun prix réel, relevé client ou résultat de terrain.
